# 数据集说明：CMIP6、EN4、ORAS5

> 内容提炼自中期检查报告（王梦佳）：研究数据准备部分。

## 总体

研究所用数据主要包括：
- **CMIP6** 模式数据（historical 试验温盐）
- **EN4** 全球海洋温盐客观分析资料（观测参考）
- **ORAS5** 海洋再分析资料（再分析对照）

智能体样本别名：`EN4` / `ORAS5` / `CMIP6`（此处 CMIP6 对应 **MME 气候态样本**）。

## CMIP6 模式选取

选取 CMIP6 historical 试验中的海洋温度（`thetao`）和盐度（`so`）月平均数据。模式选择在保证数据完整性基础上兼顾代表性：

- 需同时提供 `thetao` 与 `so`；
- historical 能覆盖研究所需时段，月尺度连续；
- 垂向层次覆盖主要研究深度；
- 优先 `r1i1p1f1` 与 `gn` 原生网格；
- 尽量兼顾不同研究机构和模式体系，控制同一模式家族数量，避免 MME 中权重过高。

目前共选取 **19 个 CMIP6 模式**，覆盖 ACCESS、BCC、CAMS、CanESM、CESM、CMCC、EC-Earth、GFDL、GISS、IPSL、MIROC、MPI、NorESM 等体系。模式均使用 Omon 月平均，变量为 `thetao`、`so`。

## EN4（观测参考）

EN4 基于多源海洋观测客观分析得到，时空覆盖较长，适合作为**历史气候态评估的主要参考场**。

中期评估中：以 EN4 作为主要参考资料，评价 CMIP6 MME 与单模式表现。

## ORAS5（再分析对照）

ORAS5 在动力模式同化框架下提供连续的三维温盐场，分辨率较高，可用于检验主要结论是否依赖单一参考资料。

通过对照 EN4 与 ORAS5：两套参考在气候态声速与声道结构上整体较为一致，其相互差异通常明显小于模式相对参考的误差。

## 多模式集合平均（MME）

为降低单个模式偶然性影响，在单模式声速气候态基础上构建 **MME（multi-model ensemble mean）**：

- 先对各模式完成 1°×1° 与 WOA102 统一并计算声速；
- 再对声速场做**等权集合平均**；
- 平均仅在海洋有效格点上进行；
- **先算声速再平均**，而不是先平均温盐再算声速，以避免声速相对温盐的非线性映射引入额外偏差。

两类 MME：
1. 1995–2014 气候平均声速场集合平均 → 历史气候态模拟能力评估；
2. 1958–2014 逐年年平均声速场集合平均 → 长期趋势分析。

## 气候态时段与评价深度

气候态评估统一取 **1995–2014**（对应 historical 末期）。智能体样本深度为 5 / 100 / 500 / 1000 / 2000 m（近表层 0 m 常全缺测，故用 5 m）。

## 在智能体中如何选用

- “观测 / EN4” → EN4
- “再分析 / ORAS5” → ORAS5
- “模式 / CMIP6 / MME” → CMIP6
- “比较模式与观测” → 通常 model=CMIP6，reference=EN4
