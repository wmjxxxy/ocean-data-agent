# 简历项目描述（做完后可用）

**海洋科研数据分析智能体｜个人项目**

- **智能体开发：**基于大模型 API 构建海洋科研数据分析智能体，通过 Tool Calling 与 RAG 分别完成数值分析和科研知识问答；支持任务路由、多步骤工具调用（Agent Loop）及带引用来源的结果生成。
- **工具与流程：**封装 NetCDF 检查、统计评价、Bias 空间绘图等 Python/xarray 工具；加入参数校验、异常处理、执行日志追踪，并约束模型避免仅凭声速 Bias 越权推断温盐机制。
- **效果评估：**构建约 60 条测试用例（含知识问答约 30 题及易混淆 hard cases），路由准确率 60/60、RAG Hit@4 达 29/29，并基于失败样例持续优化路由规则与 Prompt。

## 面试注意
